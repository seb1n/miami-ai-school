## Adding an example

Create a separate folder for each runnable example or starter project.

Each example should include:

- A README describing what it demonstrates.
- Installation and startup commands that match its actual files.
- A dependency lockfile when applicable.
- An `.env.example` with placeholders if configuration is required.
- Relevant checks and any known limitations.

Do not upload installed dependencies, build output, API keys, or private data. Add links to separate repositories in the [project index](../projects/).
