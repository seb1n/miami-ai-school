## Adding materials

1. Choose the relevant folder and course phase.
2. Group session-specific files under `session-01`, `session-02`, and so on.
3. Use descriptive filenames, such as `session-02-first-build.pptx` and `session-02-workbook.md`.
4. Link new materials from the relevant session README.
5. For a standalone application, add its repository URL to the project index. Keep runnable examples in their own folder with setup instructions.

In GitHub, open the destination folder and use **Add file > Upload files** to upload course documents. Include both an editable presentation and a PDF when available.

## Handling course content

Use sample data in exercises. Keep API credentials, private participant information, and environment files out of the repository. Add an `.env.example` containing variable names and placeholders when a code example requires configuration.
