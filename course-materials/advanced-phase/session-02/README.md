# Session 2: Build and publish Content Studio

Establish the coding environment and create the first Content Studio application from an empty folder. The presentation uses Codex and ChatGPT Sites, with Claude Code as an implementation alternative.

## Session outcomes

- Create and run a local application.
- Write project-specific AGENTS.md instructions.
- Build a content drafting workspace with server-side AI generation and durable draft storage.
- Verify the workflow and save a recoverable Git revision.
- Prepare a Sites version, deploy it, and verify access for the intended audience.
