# Source to Studio: prompt companion

Miami AI School · October 5, 2026

Build a source-reading Dify agent that turns a fictional fact pack into a newsletter, LinkedIn post, X post, and four-scene video storyboard. Review the exact draft, then run five repeatable evaluation cases and compare instruction versions.

## Open the materials

- [Interactive prompt companion](https://miami-ai-school-source-to-studio.burhansebin.chatgpt.site): searchable prompt cards with individual copy buttons.
- [Plain-text prompts](ready-to-paste-prompts.txt): the complete companion, including setup instructions, all 21 labeled copy blocks, examples, review records, and evaluation cases. Open the file and use GitHub's **Raw** button to copy or download it.

## Before class

Bring access to a Dify workspace where you can create Workflow apps and configure model providers, plus your own working OpenAI API key and API billing. Enter credentials directly into the provider settings. The optional voice demonstration uses an existing ElevenLabs account and available allowance.

Follow the named destination above each block and copy only the content between its `BEGIN` and `END` markers. The three-hour class includes a full 60-minute evaluation lab. All Bright Harbor Lab and Harbor Bike Repair details are fictional classroom material.
